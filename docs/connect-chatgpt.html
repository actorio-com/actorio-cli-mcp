Setup guide

Connect Actorio to ChatGPT

Once connected, you can ask ChatGPT to search Actorio's product index and run exports for you — directly in the chat. Every request runs against your own Actorio plan and credit balance. Takes about five minutes.

What you'll be able to do

  • Search Actorio's full product index across DE, ES, FR, GB and IT, with every filter the web app has
  • Run Amazon Flip cross-marketplace searches
  • Export a full result set as an Excel file, right into the chat
  • Check your credit balance without leaving ChatGPT

Before you start

  • A ChatGPT plan that supports custom connectors — Plus, Pro, Business, Enterprise or Edu
  • An active Actorio account and plan
  • Five minutes, and this page

Turn on Developer mode

Custom connectors live behind a setting most people never need. In ChatGPT:

  1. Open Settings → Security and login
  2. Turn on Developer mode
On a Business, Enterprise or Edu workspace, an admin may need to enable this first, under Workspace Settings → Permissions & Roles → Connected Data.

Put it to work

Just ask, in plain language:

Yes — export it

Mentioning export or download explicitly is what tells ChatGPT to hand you a real file rather than a summary table. The full set of tools it can reach:

search_productsFull catalog search, every filter the web app has

Managing the connection

You can end this connection from either side, at any time — access stops immediately, and the very next request is rejected.

FROM ACTORIO

Connected Apps

Visit your Connected Apps page in your Actorio account and select Disconnect next to ChatGPT.

FROM CHATGPT

Remove the connector

Remove Actorio from ChatGPT's own connector settings — Actorio is notified and revokes access on its end too.

What Actorio can and can't see

Actorio only ever sees the specific search or export request you make through this connector — never the rest of your ChatGPT conversation.

Your Actorio password is never shared with ChatGPT. You type it once, on Actorio's own login page, during setup.

Troubleshooting

I don't see Developer mode in Settings

Custom connectors aren't available on ChatGPT's Free tier — you'll need Plus or above. On Business/Enterprise/Edu, it may be a workspace admin setting instead.

It says "Error fetching OAuth configuration"

This shouldn't happen on a normal connection attempt. Try removing the connector and adding it again with the exact address https://mcp.actorio.com/mcp — if it persists, contact Actorio support.

ChatGPT searched, but didn't offer me a file to download

Ask for it directly — "export these" or "download as Excel." Without that, ChatGPT will often just show a summary table instead of running the export tool.

My credit balance looks out of date

Ask ChatGPT to check your Actorio usage again, or refresh the usage page directly in your account — balances sync in real time, so this is almost always a stale reply rather than a stale balance.

I approved the connection but nothing happened

Make sure the browser tab actually redirected back to ChatGPT before closing it. If it seems stuck, remove the connector and start again from Step 2.

Need a hand? Contact Actorio support, or see the full CLI & API docs at docs.actorio.com/cli.
